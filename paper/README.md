## How to Import into Overleaf

1. Go to [Overleaf](https://www.overleaf.com/) and create a **New Project &rarr; Blank Project**.
2. Upload `paper.tex` and `references.bib`.
3. In the project files, upload the figures from `../assets/demo_comparison.gif`, `../results/robust_HalfCheetah-v5/robustness_grid.png`, and `../results/robust_HalfCheetah-v5/robustness_action_delay.png`.
4. Click **Recompile** to generate your publication PDF with TeX Live.
